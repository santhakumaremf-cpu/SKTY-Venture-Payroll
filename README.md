# SKTY Venture - Payroll Web App

Full browser-based Payroll system for **SKTY Venture**.

## Features
- Worker Master (Add / Edit / Delete)
- Attendance Entry (1-15 & 16-30)
- OT Entry + Incentive
- Incentive & Busfare
- Machine Cleaning
- Gas Cylinder Allowance (₹7/day)
- Fitters & Electricians
- Staff Salaries
- Live Dashboard & Wages Abstract
- Export (JSON backup + CSV) / Import

## How to use
1. Open `index.html` in any modern browser (Chrome / Edge / Firefox)
2. Data is saved automatically in browser LocalStorage
3. Use Export page to download backup

## Live Demo
Just open the `index.html` file – no server required.
