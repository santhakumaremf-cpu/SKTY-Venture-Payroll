# SKTY Venture - Payroll Web App

Full browser-based Payroll system for **SKTY Venture**.

## Features
- Worker Master (Add / Edit / Delete)
- Attendance Entry (1-15 & 16-30)
- OT Entry + Incentive
- Incentive & Busfare
- Machine Cleaning
- Gas Cylinder Allowance (₹7/day)
- Fitters & Electricians
- Staff Salaries
- Live Dashboard & Wages Abstract
- Export (JSON backup + CSV) / Import

## How to use
1. Download the complete `SKTY_Venture_Payroll_WebApp.html` from the conversation / artifacts
2. Rename it to `index.html` if needed
3. Open it in any modern browser (Chrome / Edge / Firefox)
4. Data is saved automatically in browser LocalStorage
5. Use Export page to download backup
